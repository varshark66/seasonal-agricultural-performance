# Seasonal Agriculture Performance Analysis

## Project
**Seasonal Agriculture Performance Analysis**  
Major Project – Data Visualization

## Objective
Analyze seasonal differences in agricultural performance and identify meaningful patterns, trends, relationships and variations in crop yield, production, resource usage and economic performance.

## Dataset
Place the following file in the same folder as the Python/Notebook file:

`seasonal_agriculture_performance_dataset.csv`

Dataset size: 4,000 rows and 28 columns.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Analysis Performed
1. Dataset loading and inspection
2. Missing-value checking
3. Data cleaning
4. Seasonal yield comparison
5. Seasonal production comparison
6. Seasonal revenue and profit comparison
7. State-wise yield analysis
8. Crop-wise yield analysis
9. Irrigation-method analysis
10. Correlation analysis
11. Key findings and summaries
12. Export of summary CSV files

## How to Run

### Google Colab
1. Open the `.ipynb` file in Google Colab.
2. Upload `seasonal_agriculture_performance_dataset.csv`.
3. Run all cells from top to bottom.

### Jupyter Notebook
Keep the notebook and CSV in the same folder and run all cells.

### Python
```bash
pip install pandas numpy matplotlib seaborn
python seasonal_agriculture_analysis.py
```

## Important
The generated summary CSV files are created automatically after successful execution.
