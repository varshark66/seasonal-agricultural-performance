Project
Seasonal Agriculture Performance Analysis
Major Project – Data Visualization

Objective
Analyze seasonal differences in agricultural performance and identify meaningful patterns, trends, relationships and variations in crop yield, production, resource usage and economic performance.

Dataset
Place the following file in the same folder as the Python/Notebook file:

seasonal_agriculture_performance_dataset.csv

Dataset size: 4,000 rows and 28 columns.

Tools Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook / Google Colab
Analysis Performed
Dataset loading and inspection
Missing-value checking
Data cleaning
Seasonal yield comparison
Seasonal production comparison
Seasonal revenue and profit comparison
State-wise yield analysis
Crop-wise yield analysis
Irrigation-method analysis
Correlation analysis
Key findings and summaries
Export of summary CSV files
How to Run
Google Colab
Open the .ipynb file in Google Colab.
Upload seasonal_agriculture_performance_dataset.csv.
Run all cells from top to bottom.
Jupyter Notebook
Keep the notebook and CSV in the same folder and run all cells.

Python
pip install pandas numpy matplotlib seaborn
python seasonal_agriculture_analysis.py
